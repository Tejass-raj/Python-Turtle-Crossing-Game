# 🐢 Turtle Crossing Game using Python Turtle

A fun arcade-style game built with Python's `turtle` graphics library where players help a turtle cross a busy road while avoiding moving cars. The game demonstrates Object-Oriented Programming (OOP), collision detection, animation, event handling, and level progression.

---

## 📖 Overview

This project recreates the classic road-crossing game using Python's Turtle graphics. Players control a turtle that must safely reach the opposite side of the screen while dodging randomly generated moving cars. Each successful crossing increases the game level and makes the cars move faster, gradually increasing the difficulty.

The project follows an object-oriented design by separating the game into dedicated classes for the **Player**, **Car Manager**, and **Scoreboard**, resulting in clean, modular, and maintainable code.
